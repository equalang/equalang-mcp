**แปลทั้งไฟล์ เลย์เอาต์อยู่ครบ** เซิร์ฟเวอร์ MCP สำหรับ [Equalang](https://equalang.com) - เครื่องมือแปลภาษาด้วย AI ที่ทำงานกับไฟล์ทั้งไฟล์: ส่ง PDF ไปก็ได้ PDF กลับมา ส่งสไลด์ไปก็ได้สไลด์กลับมา ตาราง รูปภาพ และสูตรอยู่ที่เดิมครบ นอกจากนี้ยังแปลคำบรรยายและรูปภาพ เปลี่ยนเสียงและวิดีโอเป็นคำบรรยายที่แปลแล้วหรือบทถอดเสียง และแปลข้อความจำนวนมากในคราวเดียว ใช้ได้ใน Claude Code, Claude Desktop, Codex, Cursor, Windsurf, Cline, VS Code และไคลเอนต์ MCP อื่นทุกตัว

```bash
claude mcp add equalang -s user -e EQUALANG_API_KEY=el_your_key -- npx -y @equalang/mcp
```

## ฟีเจอร์

- **เข้ารูปแบบไหน ออกรูปแบบนั้น** - PDF, DOCX, PPTX, XLSX, EPUB, HTML และ TXT ได้กลับมาในรูปแบบเดิม ยังแก้ไขต่อได้ ตาราง รูปภาพ สูตร และเลย์เอาต์ของหน้าอยู่ครบ
- **คำบรรยายและรูปภาพ** - SRT และ VTT คงเวลากำกับไว้ตามเดิม เลือกให้แสดงบรรทัดต้นฉบับไว้เหนือคำแปลได้ ส่วน JPG, PNG, WebP และ BMP ได้กลับมาโดยข้อความในภาพถูกแปลแล้ว
- **เสียงและวิดีโอ** - MP3, M4A, WAV, FLAC, OGG, AAC, Opus, MP4, MOV, WebM และ MKV กลายเป็นคำบรรยายที่แปลแล้ว หรือบทถอดเสียงในภาษาที่พูด (SRT, VTT, TXT, JSON)
- **ข้อความจำนวนมาก** - สตริงที่แยกกันถูกแปลตามลำดับ หรือข้อความยาวหนึ่งข้อความ (สูงสุด 100,000 อักขระ) ที่ Equalang ตัดตามประโยคเอง รองรับกว่า 100 ภาษาสำหรับข้อความ และ 12 ภาษาสำหรับไฟล์
- **ทั้งไฟล์ ไม่ต้องคัดลอกวาง** - สูงสุด 100 MB ต่อไฟล์ จากพาธหรือ URL สาธารณะ ไม่ต้องแบ่งเนื้อหาใส่กล่องข้อความ
- **ไม่เปลืองโทเคน** - เอเจนต์ส่งพาธหรือ URL เข้าไป แล้วได้พาธกลับมา PDF 300 หน้าไม่เข้าไปอยู่ในบทสนทนาเลย
- **รู้ราคาก่อนเริ่มงาน** - `estimate_cost` ตอบค่าใช้จ่ายสูงสุดที่งานหนึ่งอาจใช้ โดยไม่มีค่าใช้จ่าย งานที่ล้มเหลวหรือถูกยกเลิกไม่เสียอะไรเลย ไฟล์บันทึกเสียงคิดค่าใช้จ่ายตามเสียงพูดที่ได้ยินจริง และเครดิตไม่มีวันหมดอายุ

## รับคีย์

สมัครที่ <https://equalang.com> แล้วสร้างคีย์ที่ <https://equalang.com/api-keys> บัญชีใหม่มีเครดิตฟรีให้ตั้งแต่เริ่ม - พอสำหรับลองแปลเอกสารหนึ่งฉบับแล้วดูผลที่ได้กลับมา

คีย์ใส่ไว้ในตัวแปรสภาพแวดล้อมในคอนฟิกของไคลเอนต์ MCP ไม่ใส่ใน URL เด็ดขาด คีย์จะแสดงเพียงครั้งเดียว Equalang เก็บไว้เฉพาะค่าแฮชของคีย์เท่านั้น ถึงไม่มีคีย์ เซิร์ฟเวอร์ก็ยังเริ่มทำงานและแสดงรายการเครื่องมือได้ ส่วนเครื่องมือที่ต้องใช้คีย์จะตอบกลับด้วยวิธีขอคีย์

## เครื่องมือ

| เครื่องมือ | ทำอะไร |
| --- | --- |
| `translate_file` | แปลไฟล์ (พาธหรือ URL สาธารณะ) เป็นอีกภาษาหนึ่ง แล้วบันทึกผลลัพธ์ไว้ข้างไฟล์ต้นฉบับ |
| `transcribe_recording` | ถอดสิ่งที่พูดในไฟล์เสียงหรือวิดีโอออกมาเป็นข้อความพร้อมเวลากำกับ (SRT, VTT, TXT, JSON) |
| `translate_text` | แปลสตริงที่แยกกัน ตามลำดับ - หรือข้อความยาวหนึ่งข้อความ ซึ่ง Equalang จะตัดตามประโยคเอง |
| `estimate_cost` | อัปโหลดไฟล์โดยยังไม่เริ่มงานใด ๆ ตอบกลับด้วยค่าใช้จ่ายสูงสุดที่งานบนไฟล์นั้นอาจใช้ พร้อม `file_id` ที่ใช้เริ่มงานได้โดยไม่ต้องอัปโหลดซ้ำ ไม่มีค่าใช้จ่าย |
| `check_job` | กลับมาติดตามงานต่อ และบันทึกผลลัพธ์เมื่องานเสร็จ |
| `cancel_job` | หยุดงานที่อยู่ในคิวหรือกำลังทำงาน งานที่ยกเลิกจะไม่ถูกคิดค่าใช้จ่าย |
| `get_credit_balance` | เครดิตของบัญชี |
| `list_languages` | รหัสและชื่อภาษา อ่านจาก API ที่ใช้งานจริง ไม่ต้องใช้คีย์ |

## สี่เรื่องที่ควรรู้

**ภาษา** รหัสมีหน้าตาแบบ `en`, `zh-CN`, `ja` แพ็กเกจนี้ไม่ได้ฝังรายการภาษาไว้: `list_languages` อ่านรหัสและชื่อจาก API ที่ใช้งานจริง (ไฟล์รองรับภาษาน้อยกว่าข้อความ) ภาษาที่ Equalang เพิ่มเข้ามาจึงใช้ได้ทันทีโดยไม่ต้องอัปเดต ไม่ต้องระบุภาษาต้นทางหากต้องการให้ตรวจจับเอง

**เครดิต** งานแต่ละงานใช้เครดิตของบัญชี - ยอดคงเหลือเดียวกับบนเว็บไซต์ - เซิร์ฟเวอร์จึงบอกให้โมเดลแจ้งค่าใช้จ่ายและขอความยินยอมก่อน โดยตัวเลขนั้นมาจาก `estimate_cost`

**งานใช้เวลาหลายนาที** เครื่องมือจะรองานของตัวเอง แต่ไม่เกินเวลาที่ไคลเอนต์ยอมให้การเรียกหนึ่งครั้ง (ค่าเริ่มต้น 50 s, `wait_seconds` สูงสุด 240) พ้นจากนั้นโมเดลจะได้รับ id ของงานและถูกบอกให้เรียก `check_job` ซึ่งจะบันทึกผลลัพธ์ไว้ในที่ที่ควรอยู่

**ขีดจำกัด** ขนาดไม่เกิน 100 MB ต่อไฟล์ ส่วน `translate_text` รับได้สูงสุด 50 ข้อความ ข้อความละ 5,000 อักขระ (20,000 ต่อการเรียกหนึ่งครั้ง) หรือข้อความเดียวไม่เกิน 100,000

## คำถามที่พบบ่อย

**PDF ที่แปลแล้วยังคงเลย์เอาต์เดิมไหม?**
คงไว้ - นี่คือหัวใจของเครื่องมือนี้ ข้อความถูกวางกลับที่เดิม ตาราง รูปภาพ และสูตรอยู่ที่เดิม ส่วน DOCX, PPTX หรือ XLSX ก็ยังแก้ไขต่อได้

**เอกสารของฉันถูกส่งให้โมเดลหรือเปล่า?**
ไม่ เซิร์ฟเวอร์อัปโหลดไฟล์ไปที่ Equalang แล้วตอบกลับด้วยพาธ งานวิจัย 300 หน้าไม่เสียโทเคนเลย

**แปลข้อความในรูปภาพได้ไหม?**
ได้ ข้อความใน JPG, PNG, WebP หรือ BMP จะถูกรู้จำ แปล แล้ววาดกลับลงในภาพ

**งานหนึ่งงานมีค่าใช้จ่ายเท่าไร?**
`estimate_cost` บอกให้ก่อนที่จะเริ่มอะไรทั้งสิ้น และไม่มีค่าใช้จ่าย ดูราคาได้ที่ <https://equalang.com/pricing>

## ออกแบบมาอย่างไร

การตัดสินใจสามข้อ แต่ละข้อมีเหตุผล:

1. **ไฟล์ไม่ผ่านโมเดลเลย** MCP ไม่มีชนิดข้อมูลแบบไฟล์ และ PDF ขนาด 5 MB ในผลลัพธ์ของเครื่องมือก็กินคอนเท็กซ์มหาศาลโดยไม่ได้บอกอะไรเลย เครื่องมือจึงรับ*ตำแหน่งของไฟล์* - พาธแบบสัมบูรณ์บนเครื่องนี้ หรือ URL `http(s)` สาธารณะ - แล้วตอบกลับด้วย*ตำแหน่งที่เขียนผลลัพธ์ไว้* URL จะถูกส่งต่อให้ Equalang ไปดึงไฟล์เอง ไม่มีการดาวน์โหลดมาที่นี่เพียงเพื่ออัปโหลดกลับขึ้นไปอีกรอบ
2. **งานหนึ่งงานอยู่ภายในการเรียกเครื่องมือครั้งเดียว** การคืน id ของงานแล้วหวังให้โมเดลคอยตรวจสถานะเอง เป็นลูปที่มักถูกทิ้งกลางคัน เครื่องมือจึงรอให้ - โดยเว้นช่วงระหว่างการตรวจแต่ละครั้งนานเท่าที่ `Retry-After` ของ API ระบุ และรายงานความคืบหน้าให้ไคลเอนต์ที่ร้องขอ - แต่ไม่เกินเวลาที่ไคลเอนต์ยอมให้การเรียกหนึ่งครั้ง (ค่าเริ่มต้น 50 s, `wait_seconds` สูงสุด 240) พ้นจากนั้นโมเดลจะได้รับ id และถูกบอกให้เรียก `check_job` โดยเซิร์ฟเวอร์จำไว้ว่าผลลัพธ์ของงานนั้นต้องไปอยู่ที่ใด
3. **คำตอบของ API ถูกถ่ายทอดต่อ ไม่ใช่เดาเอา** ความล้มเหลวลองใหม่ได้หรือไม่นั้นดูจาก `retryable` ของ API ไม่ใช่การตีความรหัสสถานะ งานจะมีค่าใช้จ่ายได้เท่าใดคือ `quote` ของ API ไม่ใช่อัตราที่คัดลอกมาใส่ในแพ็กเกจนี้ รายการภาษาอ่านจากเอกสาร OpenAPI ของ API คำขอที่สร้างงานจะใช้ `Idempotency-Key` เดียวกันตลอดการลองใหม่ของไคลเอนต์นี้เอง คำตอบที่หายไปจึงไม่มีทางกลายเป็นงานที่สองที่ถูกคิดค่าใช้จ่าย

คำตอบแต่ละครั้งถูกบอกสองแบบ - เป็นข้อความสำหรับทุกไคลเอนต์ และเป็น `structuredContent` สำหรับไคลเอนต์ที่อ่านมัน - และไฟล์ทุกไฟล์ที่เขียนออกมายังถูกระบุเป็น `resource_link` ด้วย ซึ่งเป็นวิธีที่ MCP บอกว่า "นี่คือไฟล์" โดยไม่ต้องพกไบต์ของไฟล์ไปด้วย สิ่งที่เป็นจริงกับทุกเครื่องมือ (พาธเข้า พาธออก ถามก่อนใช้จ่าย) บอกไว้ครั้งเดียวใน `instructions` ของเซิร์ฟเวอร์ ผลลัพธ์ไม่เขียนทับของเดิมเด็ดขาด: ชื่อที่ถูกใช้แล้วจะได้ ` (1)` ต่อท้าย พาธแบบสัมพัทธ์จะถูกปฏิเสธ - โปรเซสนี้ไม่ได้ใช้ไดเรกทอรีทำงานร่วมกับเอเจนต์

## พัฒนา

```bash
npm install && npm run build
node selftest.mjs                                          # โปรโตคอล รายการเครื่องมือ และเครื่องมือที่ไม่ต้องใช้คีย์
EQUALANG_API_KEY=el_... node selftest.mjs file.txt talk.mp3  # รวมถึงงานจริง (ใช้เครดิต)
node check-api.mjs                                         # พาธ ฟิลด์ และสิ่งที่คำอธิบายเครื่องมือสัญญาไว้ เทียบกับสัญญาจริงของ API
```

`EQUALANG_BASE_URL` ใช้ชี้เซิร์ฟเวอร์ไปยังดีพลอยเมนต์อื่น
