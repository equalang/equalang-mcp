# เซิร์ฟเวอร์ MCP ของ Equalang

[English](../README.md) · [简体中文](README.zh-CN.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Español](README.es.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Português](README.pt.md) · [Italiano](README.it.md) · [Русский](README.ru.md) · [Polski](README.pl.md) · [Türkçe](README.tr.md) · [Tiếng Việt](README.vi.md) · [Bahasa Indonesia](README.id.md) · **ไทย** · [हिन्दी](README.hi.md) · [العربية](README.ar.md)

ให้เอเจนต์ใช้ [Equalang](https://equalang.com) ได้: แปลไฟล์ทั้งไฟล์โดยคงเลย์เอาต์ไว้ ถอดเสียงจากไฟล์บันทึก และแปลข้อความ

- **เอกสาร** - PDF, DOCX, PPTX, XLSX, EPUB, HTML, TXT - ได้กลับมาในรูปแบบเดิม ตาราง รูปภาพ และสูตรอยู่ที่เดิมครบ
- **คำบรรยาย** (SRT, VTT) และ**รูปภาพ** (JPG, PNG, WebP, BMP)
- **เสียงและวิดีโอ** - MP3, M4A, WAV, FLAC, OGG, AAC, Opus, MP4, MOV, WebM, MKV - ได้กลับมาเป็นคำบรรยายที่แปลแล้ว หรือเป็นบทถอดเสียงในภาษาที่พูด

เอเจนต์ส่งพาธหรือ URL เข้าไป แล้วได้พาธกลับมา เนื้อหาของไฟล์ไม่เข้าไปอยู่ในบทสนทนาเลย

## ติดตั้ง

สร้างคีย์ที่ <https://equalang.com/api-keys> แล้วเพิ่มเซิร์ฟเวอร์ลงในไคลเอนต์ของคุณ:

```json
{
  "mcpServers": {
    "equalang": {
      "command": "npx",
      "args": ["-y", "@equalang/mcp"],
      "env": { "EQUALANG_API_KEY": "el_..." }
    }
  }
}
```

Claude Code: `claude mcp add --transport stdio equalang --env EQUALANG_API_KEY=el_... -- npx -y @equalang/mcp`  
Codex: `codex mcp add equalang --env EQUALANG_API_KEY=el_... -- npx -y @equalang/mcp`

ต้องใช้ Node 18 ขึ้นไป ถึงไม่มีคีย์ เซิร์ฟเวอร์ก็ยังเริ่มทำงานและแสดงรายการเครื่องมือได้ ส่วนเครื่องมือที่ต้องใช้คีย์จะตอบกลับด้วยวิธีขอคีย์

## เครื่องมือ

| เครื่องมือ | ทำอะไร |
| --- | --- |
| `translate_file` | แปลไฟล์ (พาธหรือ URL สาธารณะ) เป็นอีกภาษาหนึ่ง แล้วบันทึกผลลัพธ์ไว้ข้างไฟล์ต้นฉบับ |
| `transcribe_recording` | ถอดสิ่งที่พูดในไฟล์เสียงหรือวิดีโอออกมาเป็นข้อความพร้อมเวลากำกับ (SRT, VTT, TXT, JSON) |
| `translate_text` | แปลข้อความธรรมดาสั้น ๆ ได้สูงสุด 50 รายการ ตามลำดับ |
| `estimate_cost` | อัปโหลดไฟล์โดยยังไม่เริ่มงานใด ๆ ตอบกลับด้วยค่าใช้จ่ายสูงสุดที่งานบนไฟล์นั้นอาจใช้ พร้อม `file_id` ที่ใช้เริ่มงานได้โดยไม่ต้องอัปโหลดซ้ำ ไม่มีค่าใช้จ่าย |
| `check_job` | กลับมาติดตามงานต่อ และบันทึกผลลัพธ์เมื่องานเสร็จ |
| `cancel_job` | หยุดงานที่อยู่ในคิวหรือกำลังทำงาน งานที่ยกเลิกจะไม่ถูกคิดค่าใช้จ่าย |
| `get_credit_balance` | เครดิตของบัญชี |
| `list_languages` | รหัสและชื่อภาษา อ่านจาก API ที่ใช้งานจริง ไม่ต้องใช้คีย์ |

**เครดิต** งานแต่ละงานใช้เครดิตของบัญชี - ยอดคงเหลือเดียวกับบนเว็บไซต์ - เซิร์ฟเวอร์จึงบอกให้โมเดลแจ้งค่าใช้จ่ายและขอความยินยอมก่อน โดยตัวเลขนั้นมาจาก `estimate_cost` ไฟล์บันทึกเสียงคิดค่าใช้จ่ายตามเสียงพูดที่ได้ยินจริง จึงมักถูกกว่าที่ประมาณไว้

**ภาษา** รหัสมีหน้าตาแบบ `en`, `zh-CN`, `ja` แพ็กเกจนี้ไม่ได้ฝังรายการภาษาไว้: `list_languages` อ่านรหัสและชื่อจาก API ที่ใช้งานจริง (ไฟล์รองรับภาษาน้อยกว่าข้อความ) ภาษาที่ Equalang เพิ่มเข้ามาจึงใช้ได้ทันทีโดยไม่ต้องอัปเดต ไม่ต้องระบุภาษาต้นทางหากต้องการให้ตรวจจับเอง

**รูปแบบและขีดจำกัด** รูปแบบตามข้างต้น ขนาดไม่เกิน 100 MB ต่อไฟล์ ส่วน `translate_text` รับได้สูงสุด 50 ข้อความ ข้อความละ 5,000 อักขระ และ 20,000 อักขระต่อการเรียกหนึ่งครั้ง

## ออกแบบมาอย่างไร

การตัดสินใจสามข้อ แต่ละข้อมีเหตุผล:

1. **ไฟล์ไม่ผ่านโมเดลเลย** MCP ไม่มีชนิดข้อมูลแบบไฟล์ และ PDF ขนาด 5 MB ในผลลัพธ์ของเครื่องมือก็กินคอนเท็กซ์มหาศาลโดยไม่ได้บอกอะไรเลย เครื่องมือจึงรับ*ตำแหน่งของไฟล์* - พาธแบบสัมบูรณ์บนเครื่องนี้ หรือ URL `http(s)` สาธารณะ - แล้วตอบกลับด้วย*ตำแหน่งที่เขียนผลลัพธ์ไว้* URL จะถูกส่งต่อให้ Equalang ไปดึงไฟล์เอง ไม่มีการดาวน์โหลดมาที่นี่เพียงเพื่ออัปโหลดกลับขึ้นไปอีกรอบ
2. **งานหนึ่งงานอยู่ภายในการเรียกเครื่องมือครั้งเดียว** การคืน id ของงานแล้วหวังให้โมเดลคอยตรวจสถานะเอง เป็นลูปที่มักถูกทิ้งกลางคัน เครื่องมือจึงรอให้ - โดยเว้นช่วงระหว่างการตรวจแต่ละครั้งนานเท่าที่ `Retry-After` ของ API ระบุ และรายงานความคืบหน้าให้ไคลเอนต์ที่ร้องขอ - แต่ไม่เกินเวลาที่ไคลเอนต์ยอมให้การเรียกหนึ่งครั้ง (ค่าเริ่มต้น 50 วินาที, `wait_seconds` สูงสุด 240) พ้นจากนั้นโมเดลจะได้รับ id และถูกบอกให้เรียก `check_job` โดยเซิร์ฟเวอร์จำไว้ว่าผลลัพธ์ของงานนั้นต้องไปอยู่ที่ใด
3. **คำตอบของ API ถูกถ่ายทอดต่อ ไม่ใช่เดาเอา** ความล้มเหลวลองใหม่ได้หรือไม่นั้นดูจาก `retryable` ของ API ไม่ใช่การตีความรหัสสถานะ งานจะมีค่าใช้จ่ายได้เท่าใดคือ `quote` ของ API ไม่ใช่อัตราที่คัดลอกมาใส่ในแพ็กเกจนี้ รายการภาษาอ่านจากเอกสาร OpenAPI ของ API คำขอที่สร้างงานจะใช้ `Idempotency-Key` เดียวกันตลอดการลองใหม่ของไคลเอนต์นี้เอง คำตอบที่หายไปจึงไม่มีทางกลายเป็นงานที่สองที่ถูกคิดค่าใช้จ่าย

คำตอบแต่ละครั้งถูกบอกสองแบบ - เป็นข้อความสำหรับทุกไคลเอนต์ และเป็น `structuredContent` สำหรับไคลเอนต์ที่อ่านมัน - และไฟล์ทุกไฟล์ที่เขียนออกมายังถูกระบุเป็น `resource_link` ด้วย ซึ่งเป็นวิธีที่ MCP บอกว่า "นี่คือไฟล์" โดยไม่ต้องพกไบต์ของไฟล์ไปด้วย สิ่งที่เป็นจริงกับทุกเครื่องมือ (พาธเข้า พาธออก ถามก่อนใช้จ่าย) บอกไว้ครั้งเดียวใน `instructions` ของเซิร์ฟเวอร์ ผลลัพธ์ไม่เขียนทับของเดิมเด็ดขาด: ชื่อที่ถูกใช้แล้วจะได้ ` (1)` ต่อท้าย พาธแบบสัมพัทธ์จะถูกปฏิเสธ - โปรเซสนี้ไม่ได้ใช้ไดเรกทอรีทำงานร่วมกับเอเจนต์

## พัฒนา

```bash
npm install && npm run build
node selftest.mjs                                          # โปรโตคอล รายการเครื่องมือ และเครื่องมือที่ไม่ต้องใช้คีย์
EQUALANG_API_KEY=el_... node selftest.mjs file.txt talk.mp3  # รวมถึงงานจริง (ใช้เครดิต)
node check-api.mjs                                         # พาธ ฟิลด์ และสิ่งที่คำอธิบายเครื่องมือสัญญาไว้ เทียบกับสัญญาจริงของ API
```

`EQUALANG_BASE_URL` ใช้ชี้เซิร์ฟเวอร์ไปยังดีพลอยเมนต์อื่น ตัว API เอง: <https://equalang.com/llms.txt>
