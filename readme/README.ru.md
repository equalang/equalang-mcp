**Переводите файл — вёрстка остаётся.** MCP-сервер для [Equalang](https://equalang.com) — ИИ-переводчика, который работает с файлами целиком: PDF возвращается как PDF, презентация — как презентация, а таблицы, изображения и формулы остаются на своих местах. Он также переводит субтитры и картинки, превращает аудио и видео в переведённые субтитры или расшифровку и пакетно переводит строки. Работает в Claude Code, Claude Desktop, Codex, Cursor, Windsurf, Cline, VS Code и любом другом MCP-клиенте.

```bash
claude mcp add equalang -s user -e EQUALANG_API_KEY=el_your_key -- npx -y @equalang/mcp
```

## Возможности

- **Какой формат пришёл, такой и вернулся** — PDF, DOCX, PPTX, XLSX, EPUB, HTML и TXT возвращаются в том же формате, остаются редактируемыми, а таблицы, изображения, формулы и вёрстка страниц — на месте
- **Субтитры и картинки** — SRT и VTT сохраняют тайминг, при желании с исходной строкой над переводом; JPG, PNG, WebP и BMP возвращаются с переведённым текстом прямо на картинке
- **Аудио и видео** — MP3, M4A, WAV, FLAC, OGG, AAC, Opus, MP4, MOV, WebM и MKV превращаются в переведённые субтитры или в расшифровку на языке оригинала (SRT, VTT, TXT, JSON)
- **Текст пакетом** — отдельные строки переводятся с сохранением порядка, либо один длинный текст (до 100 000 символов), который Equalang сам делит по предложениям; 100+ языков для текста, 12 для файлов
- **Файлы целиком, без копирования** — до 100 MB на файл, по пути или публичному URL; ничего не нужно резать на куски и вставлять в текстовые поля
- **Не тратит токены** — агент передаёт путь или URL и получает в ответ пути; PDF на 300 страниц в диалог не попадает
- **Цена до запуска** — `estimate_cost` бесплатно называет максимальную стоимость задания; за неудавшиеся и отменённые задания ничего не списывается; за запись списывается только реально услышанная речь; кредиты не сгорают

## Получите ключ

Зарегистрируйтесь на <https://equalang.com> и создайте ключ на <https://equalang.com/api-keys>. Новые аккаунты получают бесплатные кредиты — их хватит, чтобы прогнать документ и посмотреть, что вернётся.

Ключ указывается в переменной окружения в конфигурации MCP-клиента и никогда — в URL. Он показывается один раз; Equalang хранит только его хеш. Без ключа сервер всё равно запускается и показывает список инструментов; инструмент, которому нужен ключ, в ответ объясняет, как его получить.

## Установка

Нужен Node 18 или новее.

<summary><b>Claude Code</b></summary>

```bash
claude mcp add equalang -s user -e EQUALANG_API_KEY=el_your_key -- npx -y @equalang/mcp
```

`-s user` подключает сервер во всех проектах; с областью по умолчанию, `local`, сервер загружается только в том каталоге, из которого была выполнена команда.
</details>

</details>

<details>
<summary><b>Claude Desktop, Cursor, Windsurf, Cline и другие клиенты с настройкой через JSON</b></summary>

Добавьте это в MCP-конфигурацию клиента — `claude_desktop_config.json`, `~/.cursor/mcp.json`, `~/.codeium/windsurf/mcp_config.json` или файл, указанный в документации вашего клиента:

```json
{

    "equalang": {
      "command": "npx",
      "args": ["-y", "@equalang/mcp"],
      "env": { "EQUALANG_API_KEY": "el_your_key" }
    }
  }
}
```
</details>

</details>

## Инструменты

| Инструмент | Что делает |
| --- | --- |
| `translate_file` | Переводит файл (путь или публичный URL) на другой язык и сохраняет результат рядом с ним. |
| `transcribe_recording` | Записывает то, что звучит в аудио- или видеофайле, в виде текста с таймкодами (SRT, VTT, TXT, JSON). |
| `translate_text` | Переводит отдельные строки с сохранением порядка — или один длинный текст, который Equalang сам делит по предложениям. |
| `estimate_cost` | Загружает файл, ничего не запуская; возвращает максимальную стоимость задания для него и `file_id`, по которому задание запускается без повторной загрузки. Бесплатно. |
| `check_job` | Возвращается к заданию и сохраняет результаты, когда оно завершено. |
| `cancel_job` | Останавливает задание, которое стоит в очереди или выполняется. За отменённое задание плата не списывается. |
| `get_credit_balance` | Кредиты аккаунта. |
| `list_languages` | Коды и названия языков, прочитанные из работающего API. Ключ не нужен. |

## Четыре вещи, которые стоит знать

**Языки.** Коды выглядят так: `en`, `zh-CN`, `ja`. Списка в самом пакете нет: `list_languages` читает коды и названия из работающего API (для файлов их меньше, чем для текста), поэтому язык, добавленный в Equalang, доступен без обновления. Не указывайте исходный язык, чтобы он определился автоматически.

**Кредиты.** Работа расходует кредиты аккаунта — тот же баланс, что и на сайте, — поэтому сервер велит модели сначала назвать стоимость и получить согласие; сумма берётся из `estimate_cost`.

**Задания занимают минуты.** Инструмент ждёт своё задание, но не дольше, чем клиент отводит на вызов (по умолчанию 50 с, `wait_seconds` до 240). После этого модель получает id задания и указание вызвать `check_job`, который сохраняет результаты туда, где им место.

**Лимиты.** До 100 MB на файл; `translate_text` принимает до 50 текстов по 5000 символов (20 000 на вызов) или один текст до 100 000.

## Частые вопросы

**Сохраняется ли вёрстка в переведённом PDF?**
Да — в этом весь смысл. Текст возвращается туда, где он был, а таблицы, изображения и формулы остаются на месте; DOCX, PPTX и XLSX остаются редактируемыми.

**Мой документ отправляется в модель?**
Нет. Сервер загружает файл в Equalang и отвечает путём. Статья на 300 страниц не стоит ни одного токена.

**Может ли он перевести текст на картинке?**
Да. Текст в JPG, PNG, WebP или BMP распознаётся, переводится и отрисовывается обратно на картинке.

**Сколько стоит задание?**
`estimate_cost` скажет об этом до запуска чего-либо, и это бесплатно. Цены — на <https://equalang.com/pricing>.

## Как это устроено

Три решения, у каждого своя причина:

1. **Файл никогда не проходит через модель.** В MCP нет файлового типа, а PDF на 5 MB в результате инструмента стоит целое состояние в контексте и ничего не сообщает. Инструмент принимает то, *где лежит файл*, — абсолютный путь на этой машине или публичный URL `http(s)` — и отвечает тем, *куда записаны результаты*. URL передаётся в Equalang, который сам скачивает файл; здесь ничего не скачивается лишь затем, чтобы загрузить снова.
2. **Задание живёт внутри одного вызова инструмента.** Вернуть id задания и надеяться, что модель будет опрашивать, — это цикл, который бросают на полпути. Инструмент ждёт сам — делая между проверками паузы такой длины, какую просит `Retry-After` из API, и сообщая о прогрессе клиенту, который его запросил, — но не дольше, чем клиент отводит на вызов (по умолчанию 50 с, `wait_seconds` до 240). После этого модель получает id и указание вызвать `check_job`; сервер помнит, куда должны попасть результаты этого задания.
3. **Ответы API повторяются, а не угадываются.** Можно ли повторить неудачный запрос, определяет `retryable` из API, а не толкование кодов статуса. Сколько может стоить задание — это `quote` из API, а не тариф, скопированный в пакет. Список языков читается из OpenAPI-документа API. Запрос, создающий задание, несёт один `Idempotency-Key` через все повторные попытки самого клиента, поэтому потерянный ответ не превратится во второе, оплаченное задание.

Ответ даётся дважды — текстом для любого клиента и как `structuredContent` для тех, кто его читает, — а каждый записанный файл дополнительно указывается как `resource_link`: так MCP говорит «вот файл», не передавая его байты. То, что верно для всех инструментов (пути на входе, пути на выходе, спрашивать перед тратой), сказано один раз, в `instructions` сервера. Результаты никогда ничего не перезаписывают: к занятому имени добавляется ` (1)`. Относительные пути отклоняются — у этого процесса и агента разные рабочие каталоги.

## Разработка

```bash
npm install && npm run build
node selftest.mjs                                          # протокол, список инструментов, инструмент без ключа
EQUALANG_API_KEY=el_... node selftest.mjs file.txt talk.mp3  # и реальные задания (расходует кредиты)
node check-api.mjs                                         # пути, поля и обещания в описаниях инструментов — сверка с действующим контрактом API
```

`EQUALANG_BASE_URL` направляет сервер на другое развёртывание.
