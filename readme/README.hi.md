# Equalang MCP सर्वर

[English](../README.md) · [简体中文](README.zh-CN.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Español](README.es.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Português](README.pt.md) · [Italiano](README.it.md) · [Русский](README.ru.md) · [Polski](README.pl.md) · [Türkçe](README.tr.md) · [Tiếng Việt](README.vi.md) · [Bahasa Indonesia](README.id.md) · [ไทย](README.th.md) · **हिन्दी** · [العربية](README.ar.md)

अपने एजेंट को [Equalang](https://equalang.com) दें: लेआउट बनाए रखते हुए पूरी फ़ाइलों का अनुवाद, रिकॉर्डिंग का ट्रांसक्रिप्शन, स्ट्रिंग का अनुवाद।

- **दस्तावेज़** - PDF, DOCX, PPTX, XLSX, EPUB, HTML, TXT - उसी फ़ॉर्मैट में लौटते हैं; तालिकाएँ, चित्र और सूत्र अपनी जगह पर रहते हैं।
- **सबटाइटल** (SRT, VTT) और **चित्र** (JPG, PNG, WebP, BMP)।
- **ऑडियो और वीडियो** - MP3, M4A, WAV, FLAC, OGG, AAC, Opus, MP4, MOV, WebM, MKV - अनूदित सबटाइटल के रूप में, या बोली गई भाषा में ट्रांसक्रिप्ट के रूप में लौटते हैं।

एजेंट एक पाथ या URL देता है और बदले में पाथ पाता है। फ़ाइल की सामग्री कभी बातचीत में नहीं आती।

## इंस्टॉल

<https://equalang.com/api-keys> पर एक कुंजी बनाएँ, फिर सर्वर को अपने क्लाइंट में जोड़ें:

```json
{
  "mcpServers": {
    "equalang": {
      "command": "npx",
      "args": ["-y", "@equalang/mcp"],
      "env": { "EQUALANG_API_KEY": "el_..." }
    }
  }
}
```

Claude Code: `claude mcp add --transport stdio equalang --env EQUALANG_API_KEY=el_... -- npx -y @equalang/mcp`  
Codex: `codex mcp add equalang --env EQUALANG_API_KEY=el_... -- npx -y @equalang/mcp`

Node 18 या उससे नया चाहिए। कुंजी के बिना भी सर्वर चालू होता है और अपने टूल की सूची देता है; जिस टूल को कुंजी चाहिए, वह बताता है कि कुंजी कैसे मिलेगी।

## टूल

| टूल | क्या करता है |
| --- | --- |
| `translate_file` | किसी फ़ाइल (पाथ या सार्वजनिक URL) का दूसरी भाषा में अनुवाद करता है और नतीजा मूल फ़ाइल के बगल में सहेजता है। |
| `transcribe_recording` | ऑडियो या वीडियो फ़ाइल में जो बोला गया है उसे समय-चिह्नित टेक्स्ट (SRT, VTT, TXT, JSON) के रूप में लिखता है। |
| `translate_text` | अधिकतम 50 छोटे सादे टेक्स्ट का, उसी क्रम में, अनुवाद करता है। |
| `estimate_cost` | कुछ भी शुरू किए बिना फ़ाइल अपलोड करता है; जवाब में बताता है कि उस पर जॉब की अधिकतम लागत कितनी हो सकती है, और एक `file_id` देता है जिससे दोबारा अपलोड किए बिना जॉब शुरू होता है। निःशुल्क। |
| `check_job` | किसी जॉब को दोबारा पकड़ता है, और पूरा हो जाने पर उसके नतीजे सहेजता है। |
| `cancel_job` | कतार में लगे या चल रहे जॉब को रोकता है। रद्द किए गए जॉब का शुल्क नहीं लगता। |
| `get_credit_balance` | खाते के क्रेडिट। |
| `list_languages` | भाषा कोड और नाम, लाइव API से पढ़े हुए। कुंजी की ज़रूरत नहीं। |

**क्रेडिट।** काम में खाते के क्रेडिट खर्च होते हैं - वही बैलेंस जो वेबसाइट पर है - इसलिए सर्वर मॉडल से कहता है कि पहले लागत बताए और सहमति ले; यह संख्या `estimate_cost` से आती है। रिकॉर्डिंग का शुल्क वास्तव में सुनी गई वाणी के हिसाब से लगता है, इसलिए लागत आम तौर पर अनुमान से कम आती है।

**भाषाएँ।** कोड `en`, `zh-CN`, `ja` जैसे होते हैं। इस पैकेज में कोई सूची पहले से नहीं रखी गई है: `list_languages` कोड और नाम लाइव API से पढ़ता है (फ़ाइलों के लिए टेक्स्ट से कम), इसलिए Equalang जो भाषा जोड़ता है वह बिना अपडेट के उपलब्ध हो जाती है। स्रोत भाषा न दें तो वह अपने-आप पहचान ली जाती है।

**फ़ॉर्मैट और सीमाएँ।** ऊपर दिए गए फ़ॉर्मैट, प्रति फ़ाइल 100 MB तक; `translate_text` 5,000 वर्णों तक के अधिकतम 50 टेक्स्ट लेता है, प्रति कॉल 20,000 वर्ण।

## यह कैसे बना है

तीन फ़ैसले, हर एक की अपनी वजह:

1. **फ़ाइल कभी मॉडल से होकर नहीं गुज़रती।** MCP में फ़ाइल नाम का कोई टाइप नहीं है, और टूल के नतीजे में 5 MB का PDF कुछ कहे बिना ही ढेर सारा कॉन्टेक्स्ट खा जाता है। टूल यह लेता है कि *फ़ाइल कहाँ है* - इस मशीन पर एक एब्सोल्यूट पाथ, या एक सार्वजनिक `http(s)` URL - और जवाब में बताता है कि *नतीजे कहाँ लिखे गए*। URL सीधे Equalang को सौंप दिया जाता है, जो उसे ख़ुद लाता है; यहाँ कुछ भी सिर्फ़ दोबारा अपलोड करने के लिए डाउनलोड नहीं होता।
2. **जॉब एक ही टूल कॉल के भीतर रहता है।** जॉब id लौटाकर मॉडल से पोलिंग की उम्मीद करना ऐसा लूप है जो बीच में ही छूट जाता है। टूल इंतज़ार करता है - हर जाँच के बीच उतनी देर रुकता है जितना API का `Retry-After` कहता है, और जिस क्लाइंट ने प्रगति माँगी है उसे प्रगति बताता है - पर उससे ज़्यादा नहीं जितना क्लाइंट एक कॉल को देता है (डिफ़ॉल्ट 50 s, `wait_seconds` अधिकतम 240)। उसके बाद मॉडल को id मिलता है और `check_job` कॉल करने को कहा जाता है; सर्वर याद रखता है कि उस जॉब के नतीजे कहाँ जाने हैं।
3. **API के जवाब दोहराए जाते हैं, अंदाज़े से नहीं बताए जाते।** कोई विफलता दोबारा आज़माई जा सकती है या नहीं, यह API का `retryable` तय करता है, स्टेटस कोड की व्याख्या नहीं। जॉब की लागत कितनी हो सकती है, यह API का `quote` बताता है, इस पैकेज में कॉपी की गई कोई दर नहीं। भाषाओं की सूची API के OpenAPI दस्तावेज़ से पढ़ी जाती है। जॉब बनाने वाला अनुरोध इस क्लाइंट के अपने सभी पुनर्प्रयासों में एक ही `Idempotency-Key` रखता है, ताकि खोया हुआ जवाब दूसरा, शुल्क वाला जॉब न बन जाए।

हर जवाब दो बार दिया जाता है - हर क्लाइंट के लिए टेक्स्ट के रूप में और जो इसे पढ़ते हैं उनके लिए `structuredContent` के रूप में - और लिखी गई हर फ़ाइल को `resource_link` के रूप में भी बताया जाता है; इसी तरह MCP बाइट ढोए बिना कहता है "यह रही फ़ाइल"। जो बात हर टूल पर लागू होती है (पाथ अंदर, पाथ बाहर, खर्च से पहले पूछो) वह एक ही बार कही गई है, सर्वर के `instructions` में। नतीजे कभी कुछ ओवरराइट नहीं करते: पहले से मौजूद नाम में ` (1)` जुड़ जाता है। रिलेटिव पाथ अस्वीकार कर दिए जाते हैं - यह प्रोसेस एजेंट की वर्किंग डायरेक्टरी साझा नहीं करता।

## डेवलपमेंट

```bash
npm install && npm run build
node selftest.mjs                                          # प्रोटोकॉल, टूल सूची, बिना कुंजी वाला टूल
EQUALANG_API_KEY=el_... node selftest.mjs file.txt talk.mp3  # और असली जॉब (क्रेडिट खर्च होते हैं)
node check-api.mjs                                         # पाथ, फ़ील्ड, और टूल विवरणों के वादे, API के लाइव कॉन्ट्रैक्ट से मिलान
```

`EQUALANG_BASE_URL` सर्वर को किसी दूसरे डिप्लॉयमेंट की ओर मोड़ता है। API स्वयं: <https://equalang.com/llms.txt>।
